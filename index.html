Sistema Solar Interativo

O projeto é uma aplicação web interativa que simula o movimento do sistema solar. Mais do que uma animação, é uma ferramenta de exploração onde o usuário tem o controle total do ambiente espacial. Desenvolvido em Vanilla Tech (HTML5, CSS3, JS) que une ciência e interatividade. Destaques Técnicos: Performance: Movimentos orbitais otimizados via CSS Keyframes. Interatividade: Sistema de navegação por arraste (Drag & Pan) e interface de dados dinâmica. UX/UI: Design imersivo com modal de instruções e suporte a atalhos de teclado (ESC). Robustez: Código preparado para falhas de mídia (imagens ausentes não quebram o layout). Diferencial: Demonstra domínio completo da manipulação do DOM e engenharia de software básica, sem depender de frameworks externos.
